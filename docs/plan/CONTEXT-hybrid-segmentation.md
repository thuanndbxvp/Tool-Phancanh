# CONTEXT: Hybrid Segmentation

## Trạng thái hiện tại
App `tool-phancanh` đang có 3 mode phân cảnh (AI, Fixed, Punctuation) làm rối rắm luồng xử lý và giao diện. 

## Mục tiêu
Loại bỏ 3 mode cũ. Tạo một "Smart Timeline" thống nhất. Tự động nội suy độ dài cảnh dựa vào lượng từ (WPS), tích hợp upload file Audio để nội suy chính xác hơn, và dùng Kyma/Gemini như một bước "Enhancement" tuỳ chọn để nắn chỉnh câu chữ cho chuẩn ngữ nghĩa.
